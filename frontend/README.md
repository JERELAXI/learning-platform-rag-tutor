# Socratic — фронтенд

SPA для навчальної платформи: каталог курсів, послідовні уроки, RAG-чат із
AI-репетитором, квізи, адмін-керування користувачами.

## Стек

React 19 · TypeScript · Vite 8 · Tailwind CSS 4 · oxlint

## Запуск

Бекенд має бути піднятий на `localhost:8000` (див. `../README.md`):

```bash
npm install
npm run dev
```

Відкрити <http://localhost:5173>. Запити на `/api` проксуються на бекенд
(`vite.config.ts`), тому в розробці браузер не робить кросдоменних запитів.
Для випадку, коли SPA віддається з власного хоста, на бекенді налаштований
CORS — змінна `CORS_ORIGINS`.

## Команди

| Команда | Що робить |
|---|---|
| `npm run dev` | dev-сервер із HMR на :5173 |
| `npm run build` | перевірка типів (`tsc -b`) + прод-збірка в `dist/` |
| `npm run lint` | oxlint |
| `npm test` | Vitest, один прогін |
| `npm run test:watch` | Vitest у режимі спостереження |
| `npm run preview` | локальний перегляд прод-збірки |

## Тести

Vitest + jsdom + Testing Library, **без Docker і без бекенду** — сервер
підміняється на рівні `fetch`. Покривають те, що руками не перевіриш:

- `api/client.test.ts` — рефреш токена на 401 із реплеєм запиту, single-flight
  (пʼять одночасних 401 дають **один** виклик `/auth/refresh`), розбір обох
  форм помилок FastAPI, 204 → `void`, FormData без `Content-Type`
- `api/tokens.test.ts` — сховище й підписки, плюс падаючий `localStorage`
  (приватний Safari) — застосунок мусить працювати без персистентності
- `api/types.test.ts` — ієрархія ролей, звуження union-типу квіза
- `hooks/useApi.test.ts` — скасування запиту при зміні фетчера, `reload`,
  збереження попередніх даних під час перезапиту
- `auth/guards.test.tsx` — `RequireAuth` і `RequireRole` за `role_level`

## Дизайн

Напрямок — сучасний продуктовий: білі поверхні на холодному фоні, один
фіолетовий акцент, емеральд зарезервований під `completed`, приглушений
zinc — під `locked`. Усі кольори, шрифт і радіус живуть як семантичні токени
в `@theme` (`src/index.css`); екрани не хардкодять hex.

Ключові рішення по лейауту:

- **Урок і чат — split-view**: матеріал ліворуч, репетитор праворуч. Видно
  одночасно і джерело, і відповідь із цитатою з нього — це і є демонстрація
  того, що RAG відповідає з матеріалів уроку, а не «з голови».
- **Верхнє меню + сайдбар уроків** усередині курсу: список уроків із замками
  й галочками завжди на екрані, тому послідовне розблокування видно постійно.
